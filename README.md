# HR-MoA Storyboard

Инструмент для работы над сериями изображений — раскадровками. 
Объединяет ComfyUI (как вычислительный движок) с чистым интерфейсом 
для генерации сцен, управления очередью и хранения истории.

Основная идея: ComfyUI занимается тем, что умеет лучше всего — держит 
модели, workflow и API. Мы даём поверх него лёгкий UI для работы 
с сериями: проекты, граф сцен, очередь задач, история генераций.

## Возможности

- **Проекты** — контейнер для серии. Каждый проект = папка на диске.
- **Граф сцен** — каждая сцена это узел, между сценами можно ставить связи.
- **Настройки сцены** — уникальные для сцены: модель, LoRA, размеры, 
  sampler, промпт, негатив. Автосохранение при любом изменении.
- **Пресеты** — наборы настроек, которые можно наследовать в сценах 
  или переопределять.
- **Очередь задач** — живёт на бэкенде, переживает перезагрузку страницы. 
  Можно поставить 100 задач и уйти пить чай.
- **История генераций** — каждая сцена ведёт историю: промпт, seed, 
  все параметры, результат.
- **WebSocket** — прогресс генерации виден на любом экране.

## Требования

- **Python 3.10+** (проверено на 3.12)
- **ComfyUI**, запущенный отдельно (по умолчанию `http://localhost:8188`)
- Windows, Linux или macOS
- Современный браузер (Chrome, Edge, Firefox)

## Первые шаги

- Убедитесь, что ComfyUI запущен (http://localhost:8188).
- Откройте Storyboard (http://localhost:9000).
- Создайте проект.
- Внутри проекта создайте сцену (двойной клик по пустому месту).
- Откроется экран генерации сцены.
- Справа — панель настроек (открывается по кнопке ☰).
    Настройте модель, LoRA, размеры.
- Введите промпт слева, нажмите Сгенерировать.
- Прогресс появится в хедере сверху. Результат — в превью справа.

## Как работает
Бэкенд (FastAPI):
Держит один WebSocket к ComfyUI. Все задачи идут через него.
Очередь задач в памяти бэкенда. Задачи выполняются последовательно.
Пишет историю генераций в JSON-файлы в проектах.
Отдаёт статику и REST API.
Фронт подключается через WS /ws/app и получает снапшот + события.
Фронт (Vanilla JS, ES6-модули):
Не хранит состояние очереди. Только рендерит то, что приходит с бэка.
Через F5 состояние восстанавливается из /api/queue.
Можно открыть несколько вкладок — они синхронизированы.
Это значит: если браузер выгрузит страницу — ComfyUI продолжит
считать. Следующий заход покажет актуальное состояние.

## Добавление своего workflow
Соберите workflow в ComfyUI из родных нод.
Экспортируйте через Save → API Format (JSON).
Положите файл в backend/templates/<имя>.json.
В интерфейсе Storyboard откройте пресеты → «Импортировать workflow».
Адаптер сгенерируется автоматически.
Поддерживаемые ноды (на момент 0.0.1):
KSampler, KSamplerAdvanced
UNETLoader, CheckpointLoaderSimple
CLIPLoader, CLIPTextEncode, PrimitiveStringMultiline
VAELoader, EmptyLatentImage
LoraLoaderModelOnly, LoraLoader
ModelSamplingAuraFlow, ModelSamplingSD3, ModelSamplingFlux
SaveImage
Если ваше workflow использует нестандартные ноды — они будут проигнорированы
при импорте адаптера. Проверить можно в поле import_info адаптера.
