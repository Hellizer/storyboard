# HR-MoA Storyboard

Инструмент для работы над сериями изображений — раскадровками.
Объединяет ComfyUI (генерация) и локальную LLM (ассистент) с чистым
веб-интерфейсом для управления проектами, сценами, промптами и историей.

Название «HR-MoA» — про рабочий процесс: **H**uman-**R**outed **M**ixture
of **A**gents. Человек — маршрутизатор: скармливает задачу то одной модели,
то другой, оценивает результат, вносит правки. Инструмент не пытается
быть умнее пользователя — он просто убирает трение из этого цикла.

## Возможности

- **Проекты** — контейнер серии. Каждый проект = папка в `~/.storyboard/`.
- **Граф сцен** — canvas-граф: сцены как узлы с превью и пропорциями.
- **Экран сцены** — промпт, seed, превью, история вариантов, табы.
- **Панель настроек сцены** — модель, LoRA, размеры, sampler, негатив.
  Автосохранение при любом изменении.
- **Пресеты** — наборы настроек, наследуются проектом и переопределяются
  сценой. CRUD + автоимпорт адаптера из API-workflow ComfyUI.
- **Кубики** — библиотека текстовых фрагментов промпта (персонажи,
  локации, стили). Простые и мульти-кубики с вложенностью, reorder,
  поиск, категории, пиннинг, drag&drop в промпт по позиции курсора.
- **Чат с LLM** — сценный ассистент на `llama-server` (OpenAI-совместимый
  API). Стриминг, VL (картинки из истории сцены + вставка из буфера),
  тумблер thinking, markdown-lite.
- **Очередь задач** — живёт на бэкенде, переживает F5 и закрытие браузера.
- **История генераций** — промпт, seed, все параметры, результат.
  Переключение вариантов восстанавливает промпт и seed.

## Требования

- **Python 3.10+** (проверено на 3.12)
- **ComfyUI** на `http://localhost:8188` (для генерации)
- **llama-server** на `http://localhost:8080` (для чата) — опционально,
  чат просто не будет работать без него, остальное не затронуто
- Windows / Linux / macOS
- Современный браузер

## Установка

    git clone https://github.com/Hellizer/storyboard.git
    cd storyboard
    pip install -r requirements.txt

## Запуск

**Бэкенд Storyboard:**

Windows:
    run.bat

Linux / macOS:
    chmod +x run.sh
    ./run.sh

Вручную:
    cd backend
    python main.py

Открой http://localhost:9000

**ComfyUI** — запускается отдельно, как обычно.

**llama-server для чата:**

Нужен `llama-server` из состава [llama.cpp](https://github.com/ggml-org/llama.cpp)
и модель с поддержкой VL (например Gemma-4-E4B). Пример запуска:

    llama-server.exe ^
        -m "Gemma-4-E4B-...-Q5_K_P.gguf" ^
        --mmproj "mmproj-Gemma-4-E4B-...-f16.gguf" ^
        -c 16186 ^
        --jinja ^
        --host 127.0.0.1 ^
        --port 8080

Флаг `--jinja` обязателен — без него не сработает `enable_thinking`.

Скрипт-обёртка `run_gemma.ps1` в корне репо — для удобства, если модель
и `llama-server.exe` лежат рядом с проектом.

## Первые шаги

1. ComfyUI запущен на `:8188`.
2. Storyboard запущен на `:9000`.
3. (Опционально) `llama-server` на `:8080` — если хочешь чат.
4. Открой http://localhost:9000, создай проект.
5. Внутри — сцена (двойной клик по пустому месту в графе).
6. Настрой модель/LoRA/размеры в панели ☰ справа.
7. Введи промпт, жми **Сгенерировать**. Прогресс — в хедере.
8. **Кубики** — таб справа. Создай «Маша», добавь подкубики (волосы,
   лицо). Клик по кубику — текст вставляется в промпт по позиции курсора.
9. **Чат** — таб справа. Прикрепи картинку из истории сцены drag&drop'ом
   или вставь скриншот из буфера Ctrl+V. Спроси «что не так с этим кадром»,
   получи предложения, скопируй удачное в промпт, сгенерируй заново.

## Как это работает

**Бэкенд (FastAPI):**
- Один WebSocket к ComfyUI на весь бэкенд.
- Очередь задач в памяти, выполняется последовательно. Переживает F5.
- Один WebSocket к `llama-server` (SSE-стриминг), проксируется
  на фронт через `/ws/chat`.
- История генераций и картинки — в JSON + PNG на диске.
- Пользовательские данные — в `~/.storyboard/` (переопределяется через
  `STORYBOARD_HOME`).

**Фронт (Vanilla JS, ES-модули, без сборщиков):**
- Один WS к бэку (`/ws/app`) для очереди + один (`/ws/chat`) для чата.
- Не хранит состояние — только рендерит то, что приходит.
- F5 не теряет ничего: очередь живёт на бэке, чат — на диске.
- Можно открыть несколько вкладок — они синхронизированы.

**Структура данных:**

    ~/.storyboard/
    ├── projects/
    │   └── <project>/
    │       ├── project.json
    │       └── scenes/<scene_id>/
    │           ├── history.json
    │           ├── chat.json
    │           ├── images/<task_id>.png
    │           └── chat_uploads/<uuid>.png
    ├── presets/
    └── cubes.json

## Добавление своего workflow

1. Собери workflow в ComfyUI из родных нод.
2. Экспортируй через **Save → API Format (JSON)**.
3. Положи в `backend/templates/<имя>.json`.
4. В Storyboard: пресеты → **Импортировать workflow**. Адаптер
   сгенерируется автоматически.

Поддерживаемые ноды:

- KSampler, KSamplerAdvanced
- UNETLoader, CheckpointLoaderSimple
- CLIPLoader, CLIPTextEncode, PrimitiveStringMultiline
- VAELoader, EmptyLatentImage
- LoraLoaderModelOnly, LoraLoader
- ModelSamplingAuraFlow, ModelSamplingSD3, ModelSamplingFlux
- SaveImage (подменяется на PreviewImage при отправке)

Если workflow использует нестандартные ноды — они будут проигнорированы
при импорте адаптера. Список — в поле `import_info` адаптера.
